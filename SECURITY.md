# Безопасность

## Поддерживаемая область

Репозиторий содержит переносимые навыки, сценарии и открытые идентификаторы
приложений авторизации. Он намеренно не содержит пользовательские токены,
закрытые ключи, клиентские выгрузки и рабочее состояние агентов.

Открытые идентификаторы приложений авторизации Яндекс Директа и Метрики не
являются секретами: они сохранены, чтобы пользователь мог войти в свой аккаунт
без создания собственного приложения. Полученные через них токены являются
секретами и должны храниться только локально в закрытых файлах.

Не добавляйте в репозиторий:

- `.env`, файлы токенов и выгрузки учётных данных;
- ключи API, пароли, закрытые части OAuth и содержимое заголовков авторизации;
- клиентские отчёты, названия закрытых кабинетов и служебные номера объектов;
- локальное состояние `.codex/`, `.claude/`, журналы применения и файлы
  подтверждений;
- закрытые доказательства `before`, `after`, `diff`, `readback` и возврата.

## Сообщение об уязвимости

Отправляйте уязвимость через закрытое сообщение GitHub Security Advisory этого
репозитория. Не создавайте открытую задачу, если описание раскрывает секрет,
способ обхода ворот записи или данные клиента.

В сообщении укажите затронутый компонент, безопасные шаги воспроизведения,
ожидаемое и фактическое поведение, а также возможный ущерб. Не прикладывайте
действующие токены и полные клиентские выгрузки.

## Если секрет уже попал в историю

1. Немедленно отзовите или замените секрет у поставщика.
2. Проверьте журналы использования и область доступа.
3. Удалите секрет из всей истории Git, а не только из последнего состояния.
4. Повторно запустите проверку утечек по рабочему дереву и полной истории.
5. Опишите происшествие без публикации значения секрета.

Удаление строки из текущего файла не делает ранее опубликованный секрет
безопасным. Сначала выполняется отзыв, затем очистка истории и повторная
проверка.

## Опасные операции

Запись в Яндекс Директ, amoCRM, Roistat, YouGile и другие внешние системы
отделена от чтения. Применение требует точного набора изменений, контрольной
суммы, ограниченного по времени разрешения, явного вооружения, состояния до и
после, контрольного чтения и кандидата на возврат.

Yandex Cloud Search API является платным маршрутом. По умолчанию он выключен;
каждый ручной вызов или заранее разрешённая серия учитывается до сетевого
запроса. Не подменяйте эти ворота повторными попытками или скрытым запасным
маршрутом.

## Проверка выпуска

Перед отправкой изменений выполните:

```bash
bash plugins/yandex-direct-for-all/scripts/release_gate.sh
```

Проверка охватывает испытания, ссылки, состав установки, запрещённые локальные
контуры и поиск секретов в дереве и истории. Выпуск нельзя считать безопасным,
если хотя бы один обязательный шаг не прошёл.
