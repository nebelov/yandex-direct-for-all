# Происхождение Wordstat v2

- Исходное хранилище: https://github.com/altrr2/yandex-tools-mcp
- Метка: v-wordstat-2.0.1
- Изменение: 4a3a55ecdc5a40b5c1a19fb32329df8065adbd14
- Лицензия: MIT, файл LICENSE сохранён.

Перенесены LICENSE, README.md, package.json, package-lock.json, src/convert.mjs, src/index.mjs и tests/conversions.test.mjs. README объединён с договором этого набора. В `convert.mjs` добавлены общий с Python межпроцессный постоянный учёт скорости и стоимости, атомарная публикация записи владельца блокировки, проверка идентичности запуска процесса и восстановление только после завершившегося или заменённого процесса-владельца; изменения подключены из `index.mjs`. Их проверки добавлены в существующий `tests/conversions.test.mjs`, чтобы не расширять утверждённый список файлов.

Проверка неизменённой логики преобразований:

    bun test tests/conversions.test.mjs

Ожидается 33 успешных проверки Node.js: 24 исходные проверки преобразований, 3 проверки общего постоянного ограничителя, 3 проверки общей схемы с Python и 3 проверки восстановления блокировки, включая повторное использование номера процесса. Дополнительно Python-коллектор проходит собственные проверки той же схемы и блокировки.
