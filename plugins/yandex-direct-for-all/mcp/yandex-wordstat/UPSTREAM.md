# Происхождение Wordstat v2

- Исходное хранилище: https://github.com/altrr2/yandex-tools-mcp
- Метка: v-wordstat-2.0.1
- Изменение: 4a3a55ecdc5a40b5c1a19fb32329df8065adbd14
- Лицензия: MIT, файл LICENSE сохранён.

Перенесены LICENSE, README.md, package.json, package-lock.json, src/convert.mjs, src/index.mjs и tests/conversions.test.mjs. README объединён с договором этого набора. В `convert.mjs` добавлены общий с Python межпроцессный постоянный учёт скорости и стоимости и единая системная блокировка `flock`: Node удерживает её через минимальный дочерний процесс стандартного Python, Python-коллектор — напрямую через стандартный модуль `fcntl`. Блокировка освобождается операционной системой при любом завершении владельца и не требует удаления или восстановления файла по номеру процесса. Изменения подключены из `index.mjs`; их проверки добавлены в существующий `tests/conversions.test.mjs`, чтобы не расширять утверждённый список исходных файлов.

Проверка неизменённой логики преобразований:

    bun test tests/conversions.test.mjs

Ожидается 33 успешных проверки Node.js: 24 исходные проверки преобразований, 3 проверки общего постоянного ограничителя, 3 проверки общей схемы с Python и 3 проверки системной блокировки и её освобождения. Дополнительно Python-коллектор проверяет ту же схему, отклонение нечисловых значений и взаимное исключение Node↔Python.
