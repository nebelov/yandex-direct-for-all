10. direct-report-wizard-library — набор сохранённых отчётов в Мастере отчётов Директа.
11. keysso-competitor-research — реклама конкурентов из Keys.so.
12. analytics-dashboard-integrity — проверка дашбордов: знаменатели, когорты, расхождение источников.
13. google-sheets-live-guard — безопасные правки живых Google Таблиц.
14. structured-output-file-integrity — целостность TSV, CSV и JSONL.
15. serp-rank-verification — проверка позиций в выдаче с доказательствами.
16. work-status-reporting — честные статусы работ.
17. client-communications-research — язык клиента и возражения из созвонов и переписки.
