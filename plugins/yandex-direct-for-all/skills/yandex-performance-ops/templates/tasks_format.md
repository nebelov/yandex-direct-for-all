# Формат предложений

Каждая строка — предложение до явного утверждения пользователем. Служебные номера ниже синтетические.

| Поле | Смысл |
|---|---|
| proposal_id | Устойчивый номер предложения |
| priority | Приоритет |
| object_type | Кампания, группа, объявление или ключевая фраза |
| object_name | Понятное название |
| object_ref | Служебная ссылка, если нужна для выполнения |
| proposed_action | Предлагаемое действие |
| proposed_value | Новое значение |
| evidence | Проверяемое основание |
| expected_effect | Ожидаемый результат |
| human_decision | Пусто до решения пользователя |

Синтетический пример:

    P-001	HIGH	campaign	Поиск / пример	10000001	REVIEW_SETTING	{"setting":"EXAMPLE","value":"NO"}	снимок до изменения	убрать неподтверждённое поведение

Сценарий не заполняет human_decision и не превращает предложение в пакет записи.
