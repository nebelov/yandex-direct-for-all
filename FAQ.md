# Частые вопросы

## С чего начинать?

С `yandex-direct-unified`. Старые навыки являются переходниками и не образуют
отдельные процессы.

## Нужно ли создавать приложение для авторизации Директа или Метрики?

Нет. В наборе сохранены два опубликованных приложения: одно для Директа,
второе для Метрики и Аудиторий. Пользователь разрешает доступ только к своему
аккаунту. Открытые `client_id` не являются секретами; токены остаются локально.

## Почему Wordstat не использует тот же вход?

Wordstat v2 работает через Yandex Cloud Search API и требует собственные
`YANDEX_WORDSTAT_API_KEY` и `YANDEX_WORDSTAT_FOLDER_ID`.

## А если у меня нет Yandex Cloud?

Используйте XMLRiver — альтернативу облаку для выдачи Яндекса и Google и
частотностей Wordstat: навык `xmlriver-serp-research`. Задайте `XMLRIVER_USER`
и `XMLRIVER_KEY`; сборщики `collect_organic_serp.sh`, `collect_ad_serp.sh` и
`collect_wordstat_wave.sh` сами выберут XMLRiver, если облачный доступ не
задан. Если заданы оба, укажите `--provider`. Для первой пробы есть общий
демо-доступ `--use-demo-key` с потолком 2 руб. за запуск.

## Выполняет ли Search API запросы сразу после установки?

Нет. `YANDEX_SEARCH_ROUTE=disabled` является безопасным состоянием. Ручной
вызов требует одноразового разрешения и закрытого журнала, заранее разрешённая
серия — закрытого файла с областью, сроком и числом вызовов.

## Куда сохраняются токены?

В закрытый локальный каталог авторизации, по умолчанию `.codex/auth`, с правами
`0700` для каталога и `0600` для файлов. Этот каталог исключён из Git.

## Что делает установщик?

Без `--apply` только показывает точный план. С `--apply` собирает поставку во
временном каталоге, готовит зависимости поиска и Wordstat, проверяет конфликты,
записывает реестр и выдаёт команду отката. Пользовательские изменения не
перезаписываются.

## Как проверить выпуск?

Запустить `bash plugins/yandex-direct-for-all/scripts/release_gate.sh`. Команда
проверяет испытания, установки, ссылки, происхождение, секреты и историю Git.
