# Memory Contract

Reusable memory belongs in this repository only when it is generic methodology, safety lessons, or public workflow documentation.

Project memory belongs outside the public bundle:

- client-specific product catalogs;
- account quirks;
- private board IDs;
- local runtime handoffs;
- raw API proofs and credentials;
- campaign-specific decisions.

When promoting a lesson from a client project, rewrite it as a generic rule and remove client identifiers, private paths, and account-specific evidence.
