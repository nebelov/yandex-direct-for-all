# Актуализация Yandex Direct For All 1.1.0

Дата проверки: 14 июля 2026 года.

## Состав

Выпуск содержит:

- единый основной навык `yandex-direct-unified` и совместимые переходники;
- Wordstat v2, собираемый из зафиксированного исходного проекта с сохранённой лицензией;
- безопасное чтение Директа и отдельные ворота точно разрешённых операций записи;
- переносимый жизненный цикл клиента и исследование коммерческого спроса;
- разделённые и воспроизводимые контуры Roistat, amoCRM и Метрики;
- платный Yandex Cloud Search API, выключенный по умолчанию и защищённый ручным либо ограниченным заранее разрешённым режимом.
- безопасные сценарии YouGile с локальной проверкой по умолчанию, точным разрешением записи и контрольным чтением.

## Авторизация Яндекса

В модуле намеренно сохранены два открытых профиля общих OAuth-приложений: для Директа и для Метрики/Аудиторий. Любой установивший модуль может разрешить доступ к своему аккаунту без создания своего приложения.

Открытые `client_id` не являются секретами. `client_secret`, коды авторизации и пользовательские токены в выпуск не входят. После авторизации токен сохраняется локально с закрытыми правами и проверяется чтением выбранной службы.

## Выпускная проверка

Единая команда:

```bash
bash plugins/yandex-direct-for-all/scripts/release_gate.sh
```

Она подтверждает:

- чистую сборку Wordstat и отсутствие уязвимостей в его зависимостях;
- все испытания Python, Node.js и командных сценариев;
- целостность ссылок, указателей навыков и состава установщика;
- отсутствие абсолютных домашних путей, запрещённых контуров и закрытых файлов;
- происхождение и лицензии внешних составляющих;
- отсутствие настоящих секретов в итоговом дереве и всей истории;
- чистую установку, повторное обновление, конфликт пользовательского файла и откат отдельно для Кодекса и Клода.
- подготовку закреплённых зависимостей поиска и Wordstat в каждой чистой установке.

На итоговом дереве команда завершилась статусом `release gate: PASS`.
