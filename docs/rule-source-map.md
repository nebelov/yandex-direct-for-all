# Карта владельцев правил

| Область | Владелец |
|---|---|
| Общий порядок, безопасность, сбор, анализ и запись | `yandex-direct-unified` |
| Методы и ограничения Wordstat v2 | `yandex-wordstat` |
| Операционные сценарии и шаблоны Директа | `yandex-performance-ops` как переходник к единому навыку |
| Исследование клиента и спроса | `yandex-direct-client-lifecycle` как переходник к единому навыку |
| Отчёты Roistat | `roistat-reports-api` |
| Сверка amoCRM | `amocrm-api-control` |
| Расходы Search API | `yandex-cloud-search-cost-control` |

При конфликте процесса побеждает единый навык. Узкий справочник сохраняет
приоритет только для фактического ограничения своего API, которого нет в общем
процессе. Клиентский документ может уточнить область клиента, но не ослабить
ворота записи и требования полноты.
