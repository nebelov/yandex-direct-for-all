# Сборка и установка дополнения

Корень дополнения: `plugins/yandex-direct-for-all`. Основная точка входа:
`skills/yandex-direct-unified/SKILL.md`. Файл `.codex-plugin/plugin.json` и
реестр `.agents/plugins/marketplace.json` используют только относительные пути.

## Проверка исходного дерева

```bash
bash plugins/yandex-direct-for-all/scripts/release_gate.sh
```

Проверка собирает Wordstat по `package-lock.json`, сервер поиска по `uv.lock`,
запускает испытания, проверяет ссылки, установку, лицензии и отсутствие секретов
в дереве и истории.

## Безопасная установка

```bash
bash plugins/yandex-direct-for-all/scripts/install_bundle.sh --target both
bash plugins/yandex-direct-for-all/scripts/install_bundle.sh --target both --apply
```

Первый вызов не записывает файлы. Перед применением установщик проверяет `uv`,
Node.js и npm, собирает каждую управляемую часть во временном каталоге, готовит
зависимости и сверяет контрольную сумму. Только после успешной подготовки всех
частей заменяются управляемые каталоги. Неизвестное пользовательское изменение
останавливает применение до записи.

После установки сохраняется закрытый реестр и печатается `RUN_ID`. Откат
восстанавливает прежние управляемые каталоги и запись реестра дополнений.

## Самодостаточность

Внутри дополнения должны оставаться все необходимые навыки, документы,
примеры, сценарии, подключаемые службы, лицензии и закреплённые зависимости.
Клиентские данные, доступы и локальные доказательства внутрь не входят.
